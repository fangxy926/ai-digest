# AI 资讯周刊（ai-digest）

> 每周一自动采集、编辑、发布的 AI 大模型中文周报（杂志排版）。

## 🌐 在线阅读

**https://fangxy926.github.io/ai-digest/**

- 首页 = 最新一期
- 往期存档：`https://fangxy926.github.io/ai-digest/issues/<日期>.html`，例如 [2026-09-28 期](https://fangxy926.github.io/ai-digest/issues/2026-09-28.html)

## 运行机制

- 数据源：RSS 库存（每 6 小时增量采集）+ 官方 sitemap + Hacker News 高分帖 + X 热点
- 每周一 08:00（北京时间）由 Hermes cron 任务「AI资讯周刊」自动编辑生成 HTML 并推送到本仓库
- 推送后 GitHub Pages 自动更新，Discord 同步收到精简版 + 链接
